## BUG-1. Вкладки поиска налезают друг на друга в EN и FR

| | |
|---|---|
| Серьёзность | Minor |
| Приоритет | Medium |
| Окружение | /en/, /fr/; Desktop 1440×900; Chrome |
| Тест-кейсы | TC-01, TC-02 |

**Шаги воспроизведения:**

1. Открыть https://www.welcs.com/en/
2. Посмотреть на вкладки над формой поиска
3. Повторить на /fr/

**Ожидаемый результат:** Вкладки стоят рядом, текст обеих виден полностью (как в ES и DE)

**Фактический результат:** Вторая вкладка заезжает на первую; в FR текст ещё и обрезан: «Recherche par destina…»

**Причина:** Вкладки свёрстаны под длину испанского текста (фиксированная ширина или жёсткое смещение)

**Решение:** Контейнер display:flex + gap, вкладки width:auto; white-space:nowrap. Хотфикс: fixes/welcs-hotfix.user.js

## BUG-2. Кнопка «Start searching now!» наезжает на фото в EN

| | |
|---|---|
| Серьёзность | Major |
| Приоритет | High |
| Окружение | /en/; Desktop 1440×900; Chrome; секция section.mdl-imgText |
| Тест-кейсы | TC-03, TC-04 |

**Шаги воспроизведения:**

1. Открыть https://www.welcs.com/en/
2. Долистать до блока «For Travellers»
3. Сравнить с тем же блоком на /es/

**Ожидаемый результат:** Как в ES, FR и DE: кнопка сразу под текстом, фото ниже кнопки

**Фактический результат:** После абзаца большой пустой отступ, кнопка заходит на фото на 45px

**Причина:** Блок .m-text в EN высотой 225px при 3 строках текста (≈70px); в ES 89px при 4 строках. В EN-тексте из CMS остались пустые абзацы или переносы (~155px). Фото .img-box позиционировано absolute и не учитывает высоту текста, поэтому кнопка на него наезжает

**Решение:** Убрать пустые <p>/<br> из EN-текста блока в CMS. Защита в CSS: .mdl-imgText .m-text p:empty{display:none}. Хотфикс: fixes/welcs-hotfix.user.js

## BUG-3. Ссылки меню Destinations в EN, FR и DE ведут на главную

| | |
|---|---|
| Серьёзность | Major |
| Приоритет | High |
| Окружение | /en/, /fr/, /de/; Desktop; меню Destinations |
| Тест-кейсы | TC-05 |

**Шаги воспроизведения:**

1. Открыть /en/
2. Destinations → Begur (Palamós, Tossa de Mar и др.)
3. Повторить на /fr/ и /de/

**Ожидаемый результат:** Открывается страница выбранного города на текущем языке

**Фактический результат:** Открывается главная страница текущего языка (в EN так ведут себя 11 городов)

**Причина:** У переводов страниц городов не заполнены ссылки в меню (в ES они есть)

**Решение:** Создать или привязать EN/FR/DE-страницы городов в CMS

## BUG-4. Пункт меню «Villas» в EN, FR и DE ведёт на испанскую версию

| | |
|---|---|
| Серьёзность | Minor |
| Приоритет | Medium |
| Окружение | /en/, /fr/, /de/; Desktop; меню Accommodation |
| Тест-кейсы | TC-06 |

**Шаги воспроизведения:**

1. Открыть /en/
2. Accommodation → Villas
3. Повторить на /fr/ и /de/

**Ожидаемый результат:** /{lang}/apartamentos/?…fid_tipos=2

**Фактический результат:** /es/apartamentos/?…fid_tipos=2

**Причина:** В меню переводов прописан URL с /es/

**Решение:** Исправить URL в настройках меню для каждого языка

## BUG-5. Ссылка LinkedIn в футере ведёт в админку

| | |
|---|---|
| Серьёзность | Minor |
| Приоритет | Medium |
| Окружение | Все языки; футер; пользователь залогинен в LinkedIn (не админ страницы WELCS) |
| Тест-кейсы | TC-07 |

**Шаги воспроизведения:**

1. Войти в LinkedIn под обычным аккаунтом
2. Открыть любую языковую версию сайта
3. Кликнуть иконку LinkedIn в футере

**Ожидаемый результат:** Открывается публичная страница компании

**Фактический результат:** Ссылка ведёт на .../company/86784925/admin/feed/posts/, LinkedIn показывает ошибку доступа. Без входа в LinkedIn обе ссылки (и в админку, и публичная) открывают страницу логина, поэтому незалогиненный посетитель разницы не заметит

**Причина:** Ссылку скопировали из панели администратора

**Решение:** Заменить на https://www.linkedin.com/company/86784925/

## BUG-6. Названия объектов не переведены в EN, FR и DE

| | |
|---|---|
| Серьёзность | Trivial |
| Приоритет | Low |
| Окружение | /en/, /fr/, /de/; карточки объектов |
| Тест-кейсы | TC-08 |

**Шаги воспроизведения:**

1. Открыть /en/
2. Просмотреть карточки объектов
3. Повторить на /fr/ и /de/

**Ожидаемый результат:** Названия объектов на языке страницы

**Фактический результат:** Названия объектов на испанском (например, «cerca de la playa»)

**Причина:** Названия объектов не переведены в CMS

**Решение:** Перевести названия объектов в CMS
